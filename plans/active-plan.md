## 1. 终局定位

- 成为「有产品的人」：账号是产品入口，不做纯流量号
- **当前阶段策略（2026-11-07 定稿）**：先做免费工具，把粉丝量和收藏量做起来；付费产品后置
- 三个月目标：粉丝 3000–8000，收藏率 > 5%，私域好友 300–500，付费 0 元（本阶段不收钱）
- **人设纪律（2026-11-07 定）**：不包装「大厂高学历」，用真实身份「刚毕业程序员下班做副业」；副业叙事以真实细节透出（耗时、成本、真实账本），不编造收入
- **第二产品线：工作流/skill**：第 4 个月测试需求、第 5–6 个月上线（卖 prompt 模板、部署方案、内容工作流，99–199 元）；前提是先有真实副业流水——先有结果再卖方法；目标人群为想做 AI 副业的开发者/博主，与大学生工具线并行

## 2. 账号设定

- 旧号 100+ 粉（原大学生学习/经验分享），粉丝是大学生 → 继续用，不换号
- 形式：真人出镜口播，化名 + 露脸；独立房间可安静录音
- 设备：仅手机，无灯无麦；单条播放破 1 万前不买任何设备

## 3. 内容策略

- 系列：《用 AI 造 10 个大学生用得上的东西》
- 定位：用 AI 给大学生造东西（毕设、项目、简历、副业）；不讲 AI 原理、不讲资讯，只做「我真的做出来了」
- 风格配方：钩子（0–3 秒先给结果）→ 吐槽共鸣 → 屏幕演示 → 降维解释 → 结尾提问换评论
- **钩子三公式（2026-11-07 对标验证）**：① 否定用户现在做的事（「你还在投 PDF 简历」「别做 PPT 了」）② 吐槽 + 视觉证据（「AI 味儿重，审美堪比电线杆广告」+ 三个效果并排）③ 结果前置（直接描述爽感，不解释背景）。3 秒内不出现自我介绍、不铺垫背景
- **标题必带可复制信号（2026-11-07 定）**：教程 / 手把手 / 1 分钟学会 / 模板和代码都给你 / 想要文档的告诉我。纯故事型标题不合格
- **对标结论（6 个账号 7 条视频）**：教方法比给成品更容易爆——观众怕学不会才收藏，收藏/点赞比 0.7–1.0（普通内容 0.1–0.2）；不露脸纯录屏同样能爆（3564 粉拿 3.6w 赞），新号有位置
- **双轨制（2026-11-07 定）**：情绪轨（祝福/加油链接页）负责破播放、涨粉、收藏；实用轨（论文总结等文件管线工具）负责立人设、沉淀产品。**情绪轨是内容素材，不是产品线**
- 第一条选题：论文 PDF 一键总结 + 答辩预测（逐字稿已写好，待存为文件）
- 第二条选题：考研加油页（填名字 + 关系 → AI 写 3 版文案 → 生成专属链接，对方打开有动效）；12 月考研季，人群精准、竞品少
- **产能（2026-11-07 修订）：目标周更 2 条，保底 1 条**；一条净工时 5–6h（稳定后），第一条 8–11h；每周可用 14–15h
  - 批量生产，不串行做：周中做 2 个 demo + 写 2 篇稿，周六一次拍 2 条（3h），周日剪发 1 条、周一二剪发第 2 条
  - **周五固定留作缓冲**，不排任务——这是能跑三个月而不是三周的原因
  - 库存制：永远留 1 条成品在草稿箱
  - 降级顺序：发库存 → 发 60 秒轻片（只演示不讲解）→ 当周只发 1 条。**断更比少更伤害大**
- 发布：19:00–21:30 时段；每条必有三件套（钩子/演示/结尾提问）
- 内容视角：偶尔透出「下班后做工具」的真实过程（花了几个晚上、API 花了多少），制造副业共鸣，不改主定位
- **内容颗粒度（2026-11-07 定）：视频讲思路，文件给步骤，不做保姆级**
  - 90 秒结构：钩子 0–3s → 痛点 3–15s → 真跑一遍演示 15–55s → 只讲三步思路不讲操作 55–75s → 「模板和代码整理好了，评论区说一声」75–90s
  - 给思路不给步骤的逻辑：给完整教程 = 观众「我会了」→ 自己去做 → 不需要你；只给思路 = 观众「懂了但懒得查」→ 收藏 + 私聊
  - 保姆级只在**某条视频爆 10w+ 且评论区大量求教程**时追加，顺序不能反——先用 90 秒验证需求，再决定花 6 小时教
  - 不做保姆级的硬约束：单条制作 6–8h，超过周更 2 条的产能上限（12–14h/周）

## 4. 免费工具策略（核心决策）

- 同一工具做两个版本：**免费版**（核心功能够用 + 水印/限次）+ **进阶版**（付费开关在代码层面预留参数，现在不启用）
- 每个工具页底部放承接入口——**给具体东西，不写「加我微信」**：「模板/源码/链接放主页了，想要的评论区说一声」；对标验证：「项目已留好，来找我拿」是这批账号的统一话术，给具体物比加好友自然
- 做**工具集合页**（一个网页聚合所有作品），给关注一个理由：「关注我，第 N 个工具下周上线」
- 记录「问价用户」：评论/私信里问价格、问定制的，单独记清单——这是后续产品的需求信号

### 4.1 技术选型（2026-11-07 定）

- 工具内核：DeepSeek V4 Flash（轻交互，约 0.02 元/次）/ V4 Pro（主力）；Kimi K3 长文档备胎；全部走 OpenAI 兼容格式 + 配置文件换模型，改一行配置升级
- 开发工作台：CodeBuddy 主用，TRAE 备胎；剪辑剪映、封面即梦、提词小白提词器（安卓）/Pages 演讲者模式（iPhone）
- 上线双路线：D1–D21 用 Vercel/CF Pages 免备案（Key 只放服务端环境变量），用于拍视频与同学试用；**D2（11-08）即提交 ICP 备案**——1 个域名 + 1 台 1核2G/3M 轻量服务器（约 700 元/年），一个应用按路径分多工具，目标 11 月底前通过
- 备案提前的原因：考研加油页的核心动作是「生成链接 → 微信发给对方 → 对方打开」，**微信会拦未备案域名**，未备案等于产品从第一天就是死的；7–20 天审核期，拖到 D14 提交就赶不上考研季
- 部署形态：**不买多个域名、不部署多个应用**。一个域名按路径分（/paper、/ppt、/kaoyan），一个应用共用限流/承接/统计，加工具 = 加一个路由。单个成本趋近于 0，与工具集合页策略一致
- 备案注意：网站名称要中性（「XX 的工具箱」能过，「论文代写」「作业助手」会被驳回）；同服务器不放未备案的公开站点

### 4.2 成本控制（免费版烧自己的 token）

- 单次成本压到 ≤ 0.02 元：输入截断 + `max_tokens` 写死 1000
- 每 IP 每天限 3 次（与免费/进阶分层对齐）；DeepSeek 后台设余额告警 + 余额即停
- 撞限提示页写「今日次数已用完，关注我明天再来」——成本熔断顺便变涨粉入口

### 4.3 选品铁律

- 每个工具立项先回答「用户为什么不直接问豆包」
- 合格：文件处理管线 / 固定模板输出 / 界面交互 / 批量处理；不合格：纯套壳问答——不做

### 4.4 双轨定位（2026-11-07 定）

- **情绪轨（祝福/加油链接页）= 内容素材**：预算一个周末、一个模板、不做迭代；KPI 是那条视频的完播率和收藏率，不追使用人数
- **实用轨（文件管线类工具）= 产品线**：要打磨、要迭代、要能通过选品铁律
- 情绪轨形态：不做「祝福卡片图」，做「打开过程」——全屏动效 + 文案逐句浮现 + 背景音乐 + 专属称呼；AI 只生成文案，页面模板渲染；**不做视频生成**（成本高一个量级，留作付费版）
- 已知风险：微信会拦未备案域名与诱导分享 → 域名尽早备案、页面不写诱导话术；UGC 需敏感词过滤 + 举报入口；v1 不做照片上传
- 技术方案：名字/文案/模板编号塞进 URL 参数（base64），无数据库、无用户系统，一个 Serverless 函数调 DeepSeek 即可

### 4.5 付费逻辑（2026-11-07 定）

- **大学生不为「日常效率」付费，只为「节点 + 后果 + 时间压力」付费**：查重（不过不能答辩）、简历（投了没回音）、考研课（一年一次）、答辩 PPT（明天要交）
- **链路长度不是付费动因**：链路只影响替代难度、决定定价空间；愿意付钱的原因是恐惧，不是效率
- 三条可收费路径：①节点工具（付费点挂时间窗口，9.9–29 元）②卖交付物不卖功能（客单 50–300，耗人力）③卖「送人的东西」（情绪轨付费意愿高于实用轨，但天花板低）
- **内容锚定大学生，产品不设人群限制**：同一工具，研究生 / 职场新人 / 教师同样买单，付费能力更强
- **付费验证只认一种方式：真实交易**。第一个工具上线即挂 9.9 永久版（去限次 + 多模板），有人付 = 路通，无人付 = 换选品。禁止用评论「好用」替代付费验证

### 4.6 推广与天花板（2026-11-08 定）

- **低频不是问题，单点低频才是**：节点产品不靠复购，靠同一窗口所有人同时涌入（4–6 月千万毕业生答辩）。解法是工具集合覆盖全年节点，不是把单工具推爆。天花板：单工具一年几千到一两万（0.1% 使用 × 1% 付费 ≈ 1200 元），要更多只能多工具或提客单（50–300 交付物）
- 渠道优先级：①抖音内容本身（占 70%，视频即推广）②搜索长尾（小红书图文 / 知乎回答 / B站完整演示，需提前 1–2 个月铺，收录后持续一年）③校园渠道（QQ 群搜「XX大学 答辩」、学院群、表白墙，同校信任转化最高，口吻是「我做了个工具免费给同学用」）④工具自传播（导出水印 + 页面「我也要做一个」）⑤DOU+ 只在自然播放破 5000 且完播健康后投 100 元测
- **不做的三件**：裂变解锁（微信判诱导分享）、校园代理（一个人跑不动）、早期投流（没验证过的内容投了白投）

## 5. 数据判断标准

- 3 秒完播率 < 40% → 钩子问题，换开头
- 完播率 < 20% → 砍时长到 60 秒内
- 点赞率 < 3% → 价值感不足，强化「我也能做」
- 涨粉 < 播放量 1% → 人设不清，强化「关注我看下一个」
- 收藏率 < 8% → 内容只是「好看」，没给到能存下来的东西（本赛道收藏率可到 15–30%），要把方法/模板/文件说清楚
